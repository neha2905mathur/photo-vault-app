🔒 Meri Private Photo Vault

Photos browser mein hi lock hoti hain. GitHub par sirf encrypted data jaata hai.

Pehle ek baar setup

GitHub ka token ek baar daalo. Ye sirf is phone mein save hoga, kahin aur nahi.

Token banane ke steps:
1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
2. Repository access: Only select repositories → photo-vault
3. Permissions → Repository permissions → Contents: Read and write
4. Generate token, copy karke neeche paste karo.

Vault kholo

Apna passphrase daalo. Ye kahin save nahi hota. Passphrase bhool gaye to photos wapas nahi aayengi.

Jo bhi chunoge woh phone mein encrypt hoke upload hoga. Ek ek karke jaayega, thoda time lagega.
